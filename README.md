# 外研版九年级英语 Unit 1–6 课外辅导工作台

这是一个免构建的静态网页工作台，面向课外辅导老师备课使用。内容已按教材 Scope and sequence 中的 6 个单元重建：Teenagers today、On the money、Past passing by、Heroes、A fine balance、Live green，提供：

- 每个单元的大纲定位、教学重点与难点
- 生词表：单词/短语、音标、中英释义和原创例句
- 语法点说明、语法习题与参考答案
- 作文解析、作文习题与示范表达
- 可直接用于课堂诊断或课后作业的原创综合习题与参考答案

## 使用方式

直接用浏览器打开 `index.html`，或在仓库根目录启动任意静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 内容说明

本项目提供的是教师备课和辅导用的原创教辅材料，不复制教材原文、听力文本或课文内容；实际授课时可结合学校进度、学生错题和当地考试要求进一步增删。
