# 外研版九年级上英语课外辅导工作台

这是一个免构建的静态网页工作台，面向课外辅导老师备课使用。内容以外研版九年级上册常见 12 个模块主题为基准，提供：

- 每个模块的教学重点与难点
- 核心单词/短语的音标、中英释义和原创例句
- 模块语法点提示
- 可直接用于课堂诊断或课后作业的原创习题与参考答案

## 使用方式

直接用浏览器打开 `index.html`，或在仓库根目录启动任意静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 内容说明

本项目提供的是教师备课和辅导用的原创教辅材料，不复制教材原文、听力文本或课文内容；实际授课时可结合学校进度、学生错题和当地考试要求进一步增删。
